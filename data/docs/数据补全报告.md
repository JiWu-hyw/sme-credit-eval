### 关键突破：高企从 170 家 → **491 家（98%）**

- 上一轮只有本地 2021 认定 + 2024 备案两份名单，命中 170 家；
- 本轮打通**高新技术企业认定工作网（工信部火炬中心 innocom）**，把浙江 2021/2022/2023/2024/2025
  五个年度的**全部备案名单**（13 份 PDF，单份 1 万–1.3 万家）全部下载解析，命中率升到 98%。
- 每户都带**命中年度**，可直接构造"资质存续/晋级"时间序列（这是 A1/A2 指标的核心输入）。

### 专利：**500/500 全量采到**（29392 件，发明 9955 件）

- 通道：**专利之星**（www.patentstar.com.cn，国家知识产权局中国专利信息中心主办）
  `POST /Account/UserLogin` 登录（**必须 https**；http 会返回假的「网站维护」页）；
  取数用 `POST /Statistics/FilterStat`，`CurrentQuery = "F XX (企业名/PA)"`。
- 每户 5 个统计口径一次拿全：`PT` 类型、`LG` 法律状态、`AD` 申请年、`IC` IPC、`IN` 发明人。
- 结果：**500 户全部命中**（覆盖率 100%），专利合计 **29392 件**（发明 9955 / 实用新型 16364 / 外观 3073），
  平均每户 58.8 件，技术广度均值 6.83 个 IPC 小类。
- 由此可直接算：3.1 发明占比、3.2 授权率（有效/全部）、3.4 技术广度（IPC 小类数）、
  3.6 核心人员（发明人数 + 前 3 集中度）、4.3 专利申请 CAGR（按 AD 年度序列）。
- **逐条明细已打通**（10-28）：`POST /Search/SearchByQuery` 必须**从浏览器页面内 fetch**，
  检索式单字段 `F XX <企业名>/PA`（写成 `/PA/YY` 返回 0 条）；返回 JSON 含
  **AB 摘要 / CL 权利要求 / IN 发明人 / IC / LG** 全字段。
- 已采 **16 家企业 / 959 件**（`500家_专利明细.csv`）；随后账号触发
  `{"Ret":405,"Msg":"您近期的行为异常，已被限制"}`，需降低到 8–10 秒/页后续跑。

### 资讯/舆情：185 户有网络提及（Bing RSS）

- 通道：`bing.com/search?q="企业全名"&format=RSS` —— 真 XML、10 条/次、500 次查询零限流；
  **必须加引号**（不加时 Bing 返回知乎/百科等兜底垃圾结果）。
- 结果：**185 户（37%）有网络提及**，1,746 条明细；官网 162 / 百科 177 / 企业平台 184 / 媒体 36。
- 语义标签：荣誉 164 / 融资 137 / 订单 70 / 风险 67。
- **0 篇 315 家是真实结论**：对 315 户做引号精确复核仅新增 7 家 → 单列 `提及分层=0篇`，不填 NAN。
- 未跑：360/百度资讯深挖真实新闻（预计 1.5 小时，边际价值有限）。
