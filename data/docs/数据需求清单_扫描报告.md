> 三层名单叠加去重后预期规模 6–10 万家；其中能匹配到 ≥1 件专利的子集（建模用）约 1.5–3 万家。

### B. 专利数据（技术要素核心原料，最大缺口）

| # | 数据项 | 来源 | 现状 |
|---|---|---|---|
| B1 | **中国专利全量**（按浙江申请人地址筛选） | BigQuery `google_patents_research.publications`（推荐）/ CNIPA 批量下载（ipdps.cnipa.gov.cn）/ GitHub 800万条集（中科大，CC BY 4.0，备选） | ❌ 原始数据未入库（脚本 `cnipa.py`、`match_patents.py` 已建） |

需要的最小字段（对应 `fact_patent` / `dws_tech_feature`）：
- 公开号 / 申请号、标题、**摘要**（SciBERT 向量化用）、申请日 / 申请年、授权日 / 授权年
- 专利类型（发明 / 实用新型 / 外观设计）、法律状态、是否授权
- **申请人**（匹配企业名）、申请人地址（区域筛选）
- **发明人**（人才流动边 / 核心人员稳定性）
- IPC 分类（技术广度 / 语义边）、前向被引数（技术影响力）
- 权利要求数、同族规模（三值评分要素）

> 路线一 BigQuery 每月有免费额度，须规划查询次数（单月 1–2 次大查询），超额切 CNIPA 批量下载。

## 2. 按特征指标体系：15 个指标 + 2 个新增指标的数据需求

> 口径契约见 `docs/数据字典-标准数据库.md §5`。改指标必须先改字典，再改 schema。

| 字典编号 | 指标 | 所需数据 | 可得性 |
|---|---|---|---|
| 3.1 | 发明专利占比 | 专利申请类型统计（B1） | ✅ 可算 |
| 3.2 | 专利授权率 | 授权状态（B1） | ✅ 可算 |
| 3.3 | 专利被引（技术影响力） | 前向引用（B1，稀疏需零值处理） | ✅ 可算 |
| 3.4 | 技术广度 | IPC 小类分布（B1） | ✅ 可算（双口径） |
| 3.5 | 专利三值评分 | 摘要向量化 + 被引/同族/权利要求数（B1 + SciBERT） | 🟡 依赖摘要向量化 |
| 3.6 | 核心人员稳定性 | 发明人连续出现年数（B1 发明人字段） | ✅ 可算 |
| 3.7 | 研发投入 | **无公开源** → 替代口径 = 研发人员占比 | ❌ 缺失（论文列为局限） |
| 4.1 | 营收复合增长率 | **无公开财报** → 替代口径 | ❌ 缺失（论文列为局限） |
| 4.2 | 员工复合增长率 | 社保 / 招聘平台（公开不全） | 🟡 部分可得 |
| 4.3 | 专利复合增长率 | 专利申请时序（B1） | ✅ 可算 |

| 4.6 | 投资机构知名度 | 非上市缺失 | ❌ 非上市缺失 |
| 5.1 | 技术转化效率 | 无产出端数据 | ❌ 暂缺（论文局限） |
| 5.2 | 资本技术协同度 | 用"资质晋级×专利增长"交互代理 | 🟡 代理 |
| **A1** | 资质晋级序列（新增） | 三层名单时间戳（A1/A3） | ✅ 公开名单直接产出 |
| **A2** | 资质存续标签（新增） | 高新 2021→2024 差分（C1） | ✅ 公开名单直接产出 |

**P0 指标 4 个中 3 个可算、1 个（融资）用代理；新增 A1/A2 是路线切换后的核心增量。**
