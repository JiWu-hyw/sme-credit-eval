## 二、昨天（10-27）做了什么

### 1. 高企命中率 34% → 98%（最大单项突破）

- **问题**：本地只有 2021 认定 + 2024 备案两份名单，500 家里只命中 170 家
- **做法**：打通**高新技术企业认定工作网**（工信部火炬中心 innocom.gov.cn），把浙江 2021/2022/2023/2024/2025 **五个年度的全部备案名单**（13 份 PDF，单份 1 万–1.3 万家）全下载解析
- **结果**：命中 **491 家（98.2%）**，且每户带**命中年度** → 可构造"资质存续/晋级"时间序列

### 2. 专利统计：500/500 全量

- **通道**：专利之星（国家知识产权局中国专利信息中心主办）
- **关键坑**：必须走 **https**（http 返回假的「网站维护」页）；`CurrentQuery = "F XX (企业名/PA)"`
- **结果**：**29,392 件**（发明 9,955 / 实用新型 16,364 / 外观 3,073），平均 58.8 件/户
- **派生指标**：技术广度均值 6.83 个 IPC 小类；申请 CAGR 均值 −0.0068

### 3. 资质与上市

- 专精特新 2023 批次：500 家全部可溯源（浙经信企业〔2023〕117 号）
- 上市识别：东财全市场名录精确匹配 → **2 家上市主体本身**（603948 建业股份、688767 博拓生物）+ 7 家上市集团子公司

### 4. 搭起可复现的采集工具箱

`_data_collect/` 下 30+ 个脚本：统一会话/节流/缓存层、断点续采、失败清单、健康检查、双击即跑的 bat。

**破局点：信用浙江（credit.zj.gov.cn，省政府官方源，免费、无额度）**

这条路踩了四个坑才通：

1. 页面有 3 个输入框，必须选 placeholder 含 **"企业名称"** 的那个（另两个是站内文章搜索）
2. `element.click()` 和 CDP 鼠标事件**都无效**（按钮在 `ivu-input-group-append` 上）
3. 只有 **CDP 真实回车键**（`Input.dispatchKeyEvent`）才触发检索
4. 结果页延迟 6–10 秒才渲染表格（期间调 `creditCheckImg`），三列 `序号|主体名称|信用代码`

**质量**：474 条全部通过 **GB 32100-2015 校验位算法**；与企查查首批 40 户逐位一致。

### 3. 成立年限核验（对应你们 xlsx 第 5 条要求）

```
中位 17.0 年 | 均值 17.3 | 最小 2.3 | 最大 42.9
≥5 年 462 户（99.8%）| ≥10 年 372 户（80.3%）
```

结论：样本里**只有 1 户成立不足 5 年**，整体非常成熟。

### 4. 数据口径统一：单源 + 全量 NAN

- 按你的要求**移除全部企查查数据**（`state_qcc_cdp.json` 停用为 `.bak`）
- 缺失一律写字符串 **`NAN`**（不是空串、不是"待补"），共 3,173 格
- 读取：`pd.read_csv(..., na_values=['NAN'])`
- 代价：**注册资本 / 参保人数全列 NAN**（信用浙江不公示这两项，而企查查是唯一来源）

### 5. 资讯舆情：11 → 185（第一步完成）

- **新通道**：`bing.com/search?q="企业全名"&format=RSS` —— 真 XML、10 条/次、500 次查询零限流
- **关键**：必须加引号；不加时 Bing 返回兜底垃圾（知乎"三国杀"、杭州市百科）
- 结果：**185 户（37%）有网络提及**，1,746 条明细

| 指标 | 覆盖 |
|---|---|
| 有网络提及 | 185 |
| 有企业官网（强判定） | 162 |
| 有百科词条 | 177 |
| 有第三方企业信息页 | 184 |
| 有新闻媒体报道 | 36 |

**语义标签**：荣誉 164 / 融资 137 / 订单 70 / 风险 67

**"0 篇"315 家是真实结论，不是缺失**：Bing 对这些企业返回无关兜底结果；对 315 户做引号精确复核仅新增 7 家 → 已单列 `提及分层=0篇`，不填 NAN（这是"隐形冠军/低调型"的研究信号）。

### 6. 专利逐条明细：接口打通，但账号被限流

**打通了**（最大技术收获）：

- `POST /Search/SearchByQuery` **必须从浏览器页面内 fetch**（Python requests 会拿到「网站维护」）
- 检索式必须单字段 `F XX <企业名>/PA`；写成 `/PA/YY` 返回 0 条
- 返回 JSON 含 **AB 摘要 / CL 权利要求 / IN 发明人 / IC IPC / LG 法律状态** 全字段

**已采**：16 家企业 / **959 件**专利明细（`500家_专利明细.csv`，18 列）

**卡点**：约 500 次查询后账号被限制 `{"Ret":405,"Msg":"您近期的行为异常，已被限制"}`，`FilterStat` 也一并失效 → 账号级限制，非接口关闭。

## 六、两条重要经验（写进脚本注释了）

1. **`float('NAN')` 不报错，返回 nan** —— 会让 `sum()` 变 nan、让 `sum(1 for r if r[col])` 把 NAN 当有值。必须显式判 NAN。
2. **"0 条"要区分三种情况**：真没数据 / 静默限流（返回 0 但应有数据）/ 查询语法错误。用**已有统计数做基准**检测假零，是今天最有效的一招。
