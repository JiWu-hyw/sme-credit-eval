### 2.2　批量导入模板列名 → **接受冻结**，追加 1 项接口需求

接受已冻结的 **6 列中文模板**（序号 / 企业名称 / 证书编号 / 来源年份 / 批次 / 发证日期，UTF-8 BOM）。

### 2.3　是否需中英双语 → **前端自决：v1 不做 i18n 框架，只做零成本预留**

**理由**：当前受众是校内评审 + 中期/结题材料，无英文界面需求；引入 vue-i18n 会牵动全部组件，

两者不该混为一谈。

**预留做法（FE-00~FE-04 期间零额外成本）**：界面文案集中到 `src/locales/zh-CN.ts` 单一字典，
组件内不写字面量；将来要国际化，只需加 `en-US.ts` + 一个切换插件，**不改任何组件**。

对后端：你提的 `data` 预留 `i18n` 字段，**我方接受但不依赖**。请注意不要在 `meta` 里新增与
契约 §6.2 必备字段清单冲突的键（`meta` 按契约「原样透传」，前端不做二次解释）。
