## 二、与原计划的偏差及原因

**Python 用了 3.9.12 而非申报口径的 3.11**，原因：

1. Python 3.11.9 安装器在本机受限环境下反复"exit 0 但无文件"（写入被拦截），多次尝试（含解除拦截）均失败；
2. 本机 Python 3.12 目录损坏（无 python.exe）；
3. Python 3.13 没有 torch cu121 的 cp313 预编译 wheel；
4. torch 2.5.1+cu121 有 cp39 wheel，且 PyG 官方索引有对应的 pt25cu121 扩展包 → **3.9.12 是唯一能全链路走通预编译 wheel 的选择**。

对项目无实质影响：PyTorch / PyG / transformers / SHAP / FastAPI 全部支持 3.9；语法层面注意不用 3.10+ 的 `match` 与 `X | Y` 类型标注即可。

## 三、安装顺序（成员复现用）

```powershell
# 1. 建 venv（用系统 Python 3.9）
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip

# 2. torch（2.4GB，建议先断点续传下载 wheel 再本地安装）
#    下载地址：https://download.pytorch.org/whl/cu121/torch-2.5.1%2Bcu121-cp39-cp39-win_amd64.whl
.venv\Scripts\python.exe -m pip install <下载目录>\torch-2.5.1+cu121-cp39-cp39-win_amd64.whl
.venv\Scripts\python.exe -m pip install torchvision==0.20.1+cu121 --index-url https://download.pytorch.org/whl/cu121

# 3. PyG（索引必须与 torch 版本严格对应）
.venv\Scripts\python.exe -m pip install torch_geometric
.venv\Scripts\python.exe -m pip install pyg_lib torch_scatter torch_sparse torch_cluster torch_spline_conv -f https://data.pyg.org/whl/torch-2.5.1+cu121.html

# 4. 其余依赖（国内建议清华镜像）
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#    （requirements.txt 中 torch/torchvision/torch-geometric 三行已装过可跳过）

# 5. SciBERT（需设镜像端点，否则连 huggingface.co 超时）
$env:HF_ENDPOINT = "https://hf-mirror.com"
#    模型已固化在 data/raw/scibert_scivocab_uncased/，团队成员直接复制该目录即可，无需重新下载
```

## 四、关键坑位备忘

| 坑 | 解决方案 |
|---|---|
| torch 2.4GB wheel 下载中断 / pip 后台任务 2 分钟被杀 | 自写 Python 断点续传脚本（`Range` 头 + 分块 + 时间预算），前台分块下载 |
| `transformers` 报 CVE-2025-32434 拒绝加载 SciBERT 的 `pytorch_model.bin`（要求 torch≥2.6，但 PyG 无 torch 2.6 的 cu121 扩展包） | **不升级 torch**，改用 `torch.load(weights_only=False)` 手动加载，剥 `bert.` 前缀、丢弃 `cls.` 头。已封装在 `src/data/load_scibert.py`，全队统一调用 |
| HuggingFace 直连超时 | 设 `HF_ENDPOINT=https://hf-mirror.com`；模型文件下载后固化到 `data/raw/scibert_scivocab_uncased/` 离线复用 |
| torch 与 PyG 版本耦合 | 严格按 `https://data.pyg.org/whl/torch-{TORCH}+{CUDA}.html` 索引安装扩展，不要混装 |
| pip 自升级 WinError 5 | 之后一律 `python -m pip` |
