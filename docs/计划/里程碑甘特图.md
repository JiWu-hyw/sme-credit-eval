## 风险与缓冲

- **数据授权风险**（知识产权/企查查 API/竞赛数据集）：前置到 M1–M2，阻塞则升级指导教师。
- **GPU/算力风险**：模型训练若本地 CPU 过慢，M3 起改为 Colab/校内算力，提前确认。
- **论文周期风险**：投稿窗口可能早于结题，论文撰写从 M5（2026-12）即启动，不压到最后。
- **软著材料**：从第一天起按规范归档核心代码与开发文档（见 README 贡献规范），避免结题前突击。

> 若某项连续两周阻塞，由负责人在周报中标记并升级给指导教师（谢文武 / 喻甫祥）。
