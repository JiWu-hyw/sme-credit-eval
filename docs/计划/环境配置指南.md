## 二、Python 3.11（最重要，先做）

项目明确要求 **Python 3.11**。当前本机可用版本为 3.9.12 与 3.13.12，均非 3.11：

- **3.13 风险**：PyTorch Geometric 及其扩展（`torch_scatter` 等）在 3.13 上轮子不完整，易装不上；
- **3.9 偏旧**：部分新包（如较新 transformers）已不支持。

**推荐做法**：安装 Python 3.11。

```bash
# 方案 A：用本项目助手安装（推荐，隔离、干净）
# 直接让我执行：install_binary 安装 Python 3.11，随后建立虚拟环境

# 方案 B：手动安装
# 1) 到 https://www.python.org/downloads/release/python-3119/ 下载 Windows installer
# 2) 安装时勾选 "Add python.exe to PATH"
python --version   # 确认输出 Python 3.11.x
```

建立虚拟环境（每个成员本地一份，不入库）：

```bash
cd <项目根目录>
python -m venv .venv
source .venv/Scripts/activate      # Git Bash
# PowerShell: .venv\Scripts\Activate.ps1
pip install -U pip
pip install -r requirements.txt
```

## 三、PyTorch + PyTorch Geometric（最容易踩坑）

PyG 扩展必须和 **torch 版本 + CUDA 版本** 严格匹配，不能只 `pip install torch-geometric`。

```bash
# 1) 先装 PyTorch（二选一）
# CPU 版（无显卡也能跑，训练慢）：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
# CUDA 12.1 版（有 NVIDIA 显卡）：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 2) 再装 PyG 及其扩展（将 TORCH 与 CUDA 换成你的版本）
pip install torch_geometric
pip install pyg_lib torch_scatter torch_sparse torch_cluster torch_spline_conv \
  -f https://data.pyg.org/whl/torch-2.2.0+cu121.html
```

> 不确定 CUDA 版本：命令行 `nvidia-smi` 查看；无显卡则一律用 CPU 版。
> 校内若无显卡，建议 M3 起改用 **Google Colab（免费 GPU）** 或校内算力平台训练。

## 四、HuggingFace / SciBERT 模型下载

SciBERT 用于文本语义向量化，首次运行需下载权重（约 400MB）。国内建议配置镜像避免超时：

```bash
# 环境变量（写入 .env，勿入库）
export HF_ENDPOINT=https://hf-mirror.com
# Windows PowerShell:
# $env:HF_ENDPOINT="https://hf-mirror.com"

python - <<'PY'
from transformers import AutoTokenizer, AutoModel
name = "allenai/scibert_scivocab_uncased"
AutoTokenizer.from_pretrained(name)
AutoModel.from_pretrained(name)
print("SciBERT 下载完成")
PY
```
