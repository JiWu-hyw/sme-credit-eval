## 一、项目在做什么（一句话到三句话）

一句话：给浙江中小科技企业做一套**"技术要素 + 成长轨迹"双驱动的信用智能评估方法**，并交付可运行的原型系统与软著材料。

三句话展开：数据层用公开数据重建浙江科技企业样本池（专精特新 500 家 + 高新/科技型三层名单 + 专利 + 工商 + 舆情）→ 图谱层建企业/专利/投资机构/核心人员/技术领域/产品六类实体异质图并按期切片 → 模型层 STGNN（GAT 空间 + GRU 时间 + 注意力融合）出 0–100 信用分 / PD → 解释层 SHAP 全局 + 局部 + "阶段-因子-权重"动态图谱 → 应用层批量评估 + 单企业深度诊断两种模式。

前端在其中承担：**T61（页面/评分展示/因子可视化）**、**T62（联调 + 软著源代码整理）**、**T44（可嵌入前端的解释结果 JSON 结构，与施汶邑共担）**、**A18 系统界面截图（论文系统章 + 软著）**。

## 三、卡住的 6 处（按严重度排，均已实测）

| # | 问题 | 证据 | 后果 |
|---|---|---|---|
| 1 | **契约 v2.0 未适配** | 后端 `api.py` 已发 `contract_ver: v2.0`；前端 `ContractMeta` 无 `contract_ver / enums_version` 字段，无启动断言；`feature_shap`（v2.0 §3.3.3 对象式）前端代码零引用，`shap_local.json` 用的是 `entries[].features[]` 结构；`credit_score: 72.2`（float）与 v2.0「`score` 整数 0–100」不符 | 后端真接口一上线，P7 解析即错位；越晚改越贵 |
| 2 | **`configs/enums.json` 没被消费** | `types/index.ts › ENTITY_KIND_LABELS` 与 `styles/theme.ts › ENTITY_COLORS` 仍是本地硬编码；v2.0 §3.3.2 要求"前端零本地映射，消费 `enums.json`" | 六类实体中英文名与颜色存在**双源**，与算法侧配图偶发不一致 |
| 3 | **后端起不来 / 路径错** | `run_api.py` 用 `"src.app.api:app"`，实际模块是 `src.app.backend.api`；`api.py` 中 `ROOT` 上溯两级落到 `project/src`，于是 `outputs/*.json` 与 `data/db/*.db` 全找不到（真实位置在 `project/`） | T62 联调无法开始 |
| 4 | **12 个端点硬编码 pending** | `api.py` 里 `data_quality / features_tree / graph_* / train_curve / roc_pr_ks / stage_factor / survival / financing …` 直接 `return pending(...)`，不读文件；前端**已产出同名契约**，后端只需换读文件 | 前端交付的契约无法直接变成接口，需要一次"接线路" |
| 5 | **两份契约目录并存** | `project/outputs/`（后端自产 5 个）vs `frontend/outputs/contracts/`（前端 26 个） | 谁是唯一出口未定；`/api/outputs/manifest` 只存在于前端期望里 |
| 6 | **软著文档已漂移** | 原型说明 v1.0 写"七个页面"，实现是 8 页（P8）；可视化契约 v1.0 写 A01–A18（A18=界面截图），实现已扩到 **A21**（A18 仪表盘 / A19 雷达 / A20 瀑布 / A21 批量） | 软著材料与代码对不上，评审逐条核会问 |

## 四、下一步：按这个顺序动

### P0 · 契约 v2.0 适配（1–2 天，纯前端，无外部依赖）

1. `types/index.ts › ContractMeta` 增 `contract_ver / enums_version / schema_version`；`http.ts` 或 `api/index.ts` 启动时断言，不匹配走"契约版本不一致，请刷新"的显式态，**不静默错渲**。
2. 删 `ENTITY_KIND_LABELS` / `ENTITY_COLORS` 本地定义，改为 `import enums from '../../configs/enums.json'`（或后端 `/api/enums`），在 `types` 层派生一次，六类实体调用点（`GraphForcePanel / NodeDetailDrawer / CentralityPanel / GraphSlicePanel / LocalGraphPanel`）统一取用。
3. `score` 收为整数、`pd` 保留原始 float；格式化只在 `utils/format.ts` 做，不把格式化数字当字段值。
4. 局部解释按 v2.0 §3.3.3 对齐：`feature_shap` 对象式（`base_value / prediction / top_k / coverage / items[]`），与 `neighbours`（边归因 ΔPD）**分区呈现、不合并排序**；未就绪 `feature_shap: null` 时占位"局部解释生成中"，**不许用全局 `importance` 顶替**。
5. 顺带补 `src/locales/zh-CN.ts`：把页面字面量集中一处，`en-US.ts` 留空文件即可，**不引 vue-i18n**。

验收：`npm run type-check` 0 error；P7/P8 冒烟全绿；新增一条"契约版本不符"的降级用例。
