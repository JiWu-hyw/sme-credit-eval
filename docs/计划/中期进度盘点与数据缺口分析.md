## 二、现有真实数据实查结论

三个文件为**同一份浙江信贷面板**（`data/raw/zhejiang_real/`，已同步网盘）：

| 文件 | 行数 | 说明 |
|---|---|---|
| zhejiang_sample_100k(1).csv | 3,465 | 13.0 MB |
| output_part(2)(1).xlsx | 3,489 | 8.85 MB |
| zhejiang_ALL_data(1).parquet | 全量 | 6.1 MB（venv 缺 pyarrow，暂不可读，见 §五-0） |

**结构**（204 列）：`label` + `userid` + `apply_time` + `x1`–`x200` + `region_code`
- 时间跨度 **202304–202409，18 个月**（月度粒度 ✅ 可切时间片）
- 企业数 **1,714**（有重复申请记录）
- 标签分布 **0: 3,137 / 1: 328（正例 9.5%）**——类别不均衡但可训练
- region_code 全部为 `ZJ` ✅ 符合"浙江省样本"设定

**这份数据能支撑什么**：信用评分基线模型（XGBoost/LR 直接训）、月度时间切片、真实标签的监督训练。
**它不能支撑什么**：见 §三——项目立项的"双维驱动"核心（技术要素 + 成长轨迹）在这份数据里完全没有。

## 三、数据缺口清单（核心）

对照《特征工程字典》15 个指标逐项核对，**现有面板只覆盖 label 和时间轴，15 个业务指标一个都没有**。缺口按优先级排列：

### 🔴 P0 — 决定项目能不能立住（必补）

> **10-13 晚更新**：xlsx 附录里发现了提供方标注的 **X1–X20 字段对照**（LIMIT_BAL/PAY_0/BILL_AMT 等信用卡类行为特征，详见 `docs/真实数据摸底报告.md`），P0-2 部分解决——x21–x200 共 180 维仍未知。同轮摸底还发现：**每企业平均仅 2.0 个月观测**（≥6 个月仅 31 家），纯时序建模不可行，STGNN 时序维须改为"跨申请月图切片"。

| # | 缺什么 | 支撑的指标 / 用途 | 建议获取渠道 | 费用估计 |
|---|---|---|---|---|
| 1 | **userid ↔ 真实企业的映射键**（统一社会信用代码 / 企业名称） | 一切外部数据关联的前提！没有它，专利/融资/工商数据都接不上面板 | 向数据提供方（大赛方/老师）索要；这是**第一优先级**，拿不到则外部数据只能另建独立样本集 | 0（问来的） |
| 2 | **x1–x200 字段语义字典** | 可解释性叙事（SHAP 报告必须说"哪个业务因子重要"，不能说"x37 重要"） | 同上，向数据提供方索要 | 0 |
| 3 | **label 代理标签定义**（违约？经营异常？观察窗多长？） | 开题要求交付《代理标签定义说明书》；论文实验节必需 | 向数据提供方确认 + 自己写成文档 | 0 |
| 4 | **企业专利数据**（申请号/类型/法律状态/IPC/被引/摘要） | inv_patent_ratio、grant_rate、patent_citation、tech_breadth、patent_triple_score、patent_cagr（6 个指标，含 2 个 P0） | ① CNIPA 官方检索免费批量下载；② 学校图书馆 Incopat/万方（已购，免费）；③ 企查查 API 专利模块 | 0 ~ 包含在 API 预算内 |
| 5 | **融资事件与投资机构数据**（轮次/金额/估值/机构名） | funding_to_last_val(P0)、investor_prestige、m_funding | 企查查/天眼查 API（预算内 ¥3,000）；IT桔子/烯牛免费数据可补充 | ≤ ¥3,000（已列预算） |

### 🟡 P1 — 决定"双维"叙事完不完整（争取补）

| # | 缺什么 | 支撑的指标 | 建议获取渠道 |
|---|---|---|---|
| 6 | 工商基础信息（成立时间/注册资本/行业/参保人数） | emp_cagr、企业年龄分层、图谱企业节点属性 | 企查查 API 同上 |
| 7 | 核心人员任职/变更（高管、发明人） | core_staff_stability、m_team、人才流动网络 | 企查查任职接口 + CNIPA 发明人字段（免费） |
| 8 | 经营/财务替代数据（营收披露、招聘信息） | rev_cagr(P0 但披露率低)、rd_intensity 替代口径（研发人员占比） | 企查查年报模块 + 招聘平台公开页 |
| 9 | 资质认定（高新/专精特新名单） | m_cert | 浙江省科技厅/经信厅公示名单（免费，浙江省公共数据平台） |
| 10 | 专利摘要 + 新闻公告文本语料 | SciBERT 语义向量化、patent_triple_score、m_cite | CNIPA 摘要（免费）+ 新闻爬虫（模型已就绪，只缺语料） |

### 🔵 P2 — 可暂缓
- 税务/财报明细（rd_intensity 首选口径）、cap_tech_synergy 所需的精细时序对齐数据。字典已定替代口径，结题前视情况补。

### 数据层面的其他坑
- **类别不均衡**（9.5% 正例）：训练需加权/采样，已在计划中。
- ** parquet 读不了**：venv 未装 pyarrow（§五-0）。
- **1,714 家企业样本量偏小**：若映射键拿不到、需要自建样本集，建议用企查查 API 按"浙江 + 科技型中小企业"批量拉 3,000–5,000 家，与面板并用或替代。
