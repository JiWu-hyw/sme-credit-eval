## 本季度研究进展

重点推进开发环境搭建与数据资产建设。完成 Python 3.9.12 + PyTorch 2.5.1+cu121 + PyTorch Geometric 2.6.1 + SciBERT 全链路开发环境搭建与版本固化，编写环境自检脚本并验证通过；完成真实数据集（浙江中小科技企业信贷面板）的获取、入库与一致性核验。

## 阶段性成果

1. 完成统一开发环境搭建，自检脚本 `tests/selfcheck.py` 输出 ENV HEALTHY，保障团队成员可复现；
2. 获取浙江中小科技企业信贷面板数据，3,465 条记录 × 204 维（含违约标签、申请时点、200 维企业特征），完成 csv / xlsx / parquet 三格式入库核验；
3. 产出《数据管道架构设计》初稿，明确数据采集、预处理与存储的技术方案；
4. 完成 SciBERT 语义向量化模块（`src/data/load_scibert.py`），为专利与新闻文本处理做好准备。

2. 面板数据中 200 维特征缺乏完整字段语义说明，影响后续可解释性分析的业务解读。

# 第三份（2026 年第三季度）

## 本季度研究进展

完成数据预处理流水线、基线模型与图模型的实验验证，形成"数据 → 图谱 → 模型 → 解释"全链路可运行骨架。本季度是技术研发的密集推进期，在真实数据上完成了从预处理到模型评估的完整验证。

## 阶段性成果

1. **数据预处理流水线**：实现按企业分组切分防泄漏、训练集中位数填充、1%/99% 分位缩尾、Z-score 标准化（统计量仅在训练集拟合），产出标准化企业级特征表与《数据质量报告》，作为下游模块的接口契约；
2. **统一评估指标体系**：实现 AUC、KS、准确率、精确率、召回率、F1 及最优阈值搜索，确保不同模型在同一切分口径下可比；
3. **基线模型实验**：完成 Logistic 回归与 XGBoost 基线建模，5 折按企业分组交叉验证 AUC 分别为 0.596、0.595；通过置换对照实验（打乱标签）确认噪声地板为 0.477，验证所学信号真实存在；
4. **可解释性模块**：完成 SHAP 全局解释，输出特征贡献排序、全局重要性图及可嵌入前端的 JSON 结果结构；
5. **图神经网络模型**：基于真实面板自建异质图（记录/企业/画像簇三类节点，归属/画像/特征相似六种边），实现 GAT 模型并与无图 MLP 对照，量化验证图结构增益；
6. **时空图架构验证**：构建六类实体（企业/专利/投资机构/人员/领域/产品）合成异质图，实现 STGNN 原型（GAT + GRU + 注意力融合 + MLP），合成数据 AUC 0.9149、KS 0.8218；
7. **可视化原型**：完成基于 ECharts 的本地化可视化看板；
8. **文档体系**：产出《真实数据摸底报告》《实验结果报告（基线/SHAP/GAT）》等技术文档，累计技术文档 10 余份。

## 存在问题

1. 企业侧外部数据（专利、融资、工商）获取受阻：提供方无法提供企业映射键与特征字段字典，原数据关联路径行不通，多源数据融合环节较原计划滞后；
2. 真实面板区分度有限（行级 AUC≈0.59），实证表明瓶颈在特征维度缺乏技术要素与成长轨迹指标，而非模型算法本身；
3. SHAP 99% 贡献集中在语义未知的特征维度上，业务层解读有待字段字典补齐。

## 下一步计划

1. 落地公开数据源替代方案（零预算）：抓取浙江省科技型中小企业/高新技术企业/专精特新三层公示名单构建浙江科技企业样本池；通过 Google Patents 公开数据集（BigQuery）与国家知识产权局官方批量数据获取专利并计算技术要素特征；构造"高新资格动态"公开标签；引入 Kaggle MSME 公开信用数据集作对照；
2. 构建企业-专利-技术领域-发明人四类实体异质图，按年度切片；
3. 新特征表上重跑基线、GAT 与无图对照实验，与原行为面板做跨源对比；
4. 启动前端界面开发。

## 经费使用

本季度未发生实际支出；经公开数据源调研验证，原计划的 API 采购（预算 3,000 元）不再需要，数据购置预算保留至结题阶段使用。
