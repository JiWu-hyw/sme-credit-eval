## 一、对照申报书项目进展情况

### 1. 项目进展概述

本项目自启动以来，已完成开发环境统一搭建与全链路技术路线验证，形成"数据→图谱→模型→解释"四个环节均可运行的实验骨架，并完成真实数据资产的获取、入库与标准化处理。

对照申报书计划的三阶段任务：第一阶段"数据采集与预处理"核心工作已完成，产出标准化企业级特征表与数据质量报告；第二阶段"企业时空演化图谱构建"已完成图谱方案设计、面板自建异质图实现及六类实体合成图架构验证；第三阶段"可解释 STGNN 信用评估模型"已完成模型原型开发，在真实数据上跑通基线模型（Logistic 回归、XGBoost）与图模型（GAT）的量化对比实验，并同步完成 SHAP 全局解释模块。

受企业侧外部数据（专利、融资、工商）获取周期较长的影响，多源数据融合环节进度较原计划有所滞后，已通过专项盘点明确缺口清单与获取路径，并采用"合成数据验证方法、真实面板落地实验"双轨并行策略保障研究连续性。

### 2. 已取得项目成果

1. **环境与工程基础**：完成 Python 3.9.12 + PyTorch 2.5.1+cu121 + PyTorch Geometric 2.6.1 + SciBERT 全链路开发环境搭建，环境自检脚本通过（ENV HEALTHY），统一依赖版本与镜像源，保障团队成员可复现。
2. **数据资产建设**：获取浙江中小科技企业信贷面板数据（3,465 条记录 × 204 维，含违约标签、申请时点与 200 维企业特征），完成 csv / xlsx / parquet 三种格式入库与一致性核验，并同步至项目共享网盘。
3. **数据预处理流水线**：实现标准化预处理流程——按企业分组切分防泄漏、训练集中位数填充、1%/99% 分位缩尾、Z-score 标准化（统计量仅在训练集拟合），产出标准化特征表与《数据质量报告》，作为下游图谱与模型模块的接口契约。
4. **统一评估指标体系**：实现 AUC、KS、准确率、精确率、召回率、F1 及最优阈值搜索，保证基线模型与图模型在同一切分口径下可比。
5. **基线模型实验**：完成 Logistic 回归与 XGBoost 基线建模，采用 5 折按企业分组交叉验证，AUC 分别达 0.596 与 0.595；通过置换对照实验（打乱标签）确认噪声地板为 0.477，验证模型所学信号真实存在。
6. **可解释性模块**：完成 SHAP 全局解释，输出特征贡献排序、全局重要性图及可嵌入前端的 JSON 结果结构，为业务侧因子解读提供工具基础。
7. **图神经网络模型**：基于真实面板自建异质图（记录、企业、画像簇三类节点，归属、画像、特征相似六种边），实现 GAT 模型并与无图 MLP 对照组进行量化比较，验证图结构的性能增益。
8. **时空图架构验证**：构建企业、专利、投资机构、核心人员、技术领域、产品六类实体合成异质图，实现 STGNN 原型（GAT 空间聚合 + GRU 时间建模 + 注意力融合 + MLP 输出），在合成数据上 AUC 0.9149、KS 0.8218，验证架构可训练、可收敛。
9. **可视化原型**：完成基于 ECharts 的本地化可视化看板，支持信用评分分布展示与单企业图谱解释展示。
10. **文档与规范体系**：产出《特征工程字典》《数据管道架构设计》《任务看板》《进度安排计划》《里程碑甘特图》《环境配置指南》《真实数据摸底报告》《实验结果报告》等技术文档 10 余份，并建立任务清单与团队分工机制。

### 3. 下一阶段研究思路及措施

针对当前进度与数据获取瓶颈，下阶段采取五项措施：

（1）**数据源重建（公开数据路线，零预算）**：放弃对单一企业侧数据源的依赖，改用全公开数据重建主数据集——抓取浙江省科技型中小企业、高新技术企业、专精特新三层公示名单构建浙江科技企业样本池；通过 Google Patents 公开数据集（BigQuery）与国家知识产权局官方批量数据获取专利，计算技术要素特征；构造"高新资格动态"标签（2021 年认定队列观察至 2024 年复核）；同步引入 Kaggle MSME 公开信用数据集作对照验证。

（2）**图谱升级**：构建企业、专利、技术领域（IPC）、发明人四类实体异质图，含申请-授权、IPC 归属、共有发明人（人才流动）、专利被引（知识扩散）四类语义边，按年度切片形成时空演化图谱——人才流动边为纯外部独立信息，直接回应立项"多源异构数据融合"难题。

（3）**模型深化**：STGNN 在真实数据上完成端到端训练，与 Logistic 回归、XGBoost、GCN 完成系统性基准对比，形成论文主实验。

（4）**解释与预测**：完成局部解释（边扰动归因）与"阶段-因子-权重"动态决策图谱；开展生存力与融资力前瞻预测建模。

（5）**系统与交付**：完成后端 API 与前端界面联调，形成可部署原型系统并启动软件著作权申报；同步推进论文撰写与政策建议摘要。
