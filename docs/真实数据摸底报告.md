## 1. 三文件关系结论

| 文件 | 行数 | 与 csv 关系 |
|---|---|---|
| zhejiang_sample_100k(1).csv | 3,465 | 基准 |
| zhejiang_ALL_data(1).parquet | 3,465 | **与 csv 完全同一份数据**（userid+apply_time 3465 键全重合，200 个 x 特征逐值比对最大差 4.4e-16 = 浮点精度噪声，label 完全一致）。"ALL" 命名有误导性，**它不是全量超集** |
| output_part(2)(1).xlsx | 3,488 | csv 的 3,465 行 + 2 空行 + 1 表头行 + **21 行字段对照附录（X1–X20）** |

**结论：三个文件只需留 csv（或 parquet，二进制读取更快）作训练数据，xlsx 只因附录有价值。**

## 2. 面板结构（训练可行性）

- 3,465 行 × 204 列（label / userid / apply_time / x1–x200 / region_code）
- 企业 1,714 家；时间 202304–202409（18 个月，月度）
- 标签：0=3,137 / 1=328（正例 9.5%，需不均衡处理）；正例企业 157 家
- region_code 全部 `ZJ`
- x1–x200 全为 float64，无类别型编码痕迹；平均缺失 7.2%，13 列缺失 >50%
- **面板纵深很浅：每企业平均只有 2.0 个月观测（中位数 2，最多 16）**；≥6 个月仅 31 家（1.8%），≥12 个月仅 5 家
  - ⚠️ 含义：真实数据做 **GRU/TCN 时间序列建模基本不可行**（序列太短），更现实的做法是"截面特征 + 图结构"建模——恰好与我们的 GAT 异质图路线匹配；时间维主要靠**申请月切片**而非逐企业长序列。这一点对论文方法节表述和 T23（时间切片方案）设计有直接影响。

## 4. 仍未知（须向数据提供方确认）

1. **x21–x200 的语义**（附录只到 X20，180 维未知——占特征面 90%）
2. **label 精确定义**：违约判定口径（逾期天数？DPD30+？）、观察窗长度（apply_time 后几个月？）
3. **userid 映射键**：是否可对应到企业（统一社会信用代码/名称），还是纯脱敏个人 ID
4. 数值变换方式：是否已做归一化/WOE 编码，还原口径是什么

## 5. 对模型的直接结论

- ✅ 可立即做：XGBoost/LR 基线、GAT 异质图（企业为节点、需要外部数据建边）、SHAP 全局解释
- ⚠️ 受限：纯时序建模（每企业仅 2 个月观测）——STGNN 的"时序维"应改为**跨申请月的图切片**而非企业内长序列
- ❌ 不可做（数据缺失）：技术要素 6 指标、融资 2 指标等 15 个字典指标——维持缺口清单结论，需购/采外部数据
