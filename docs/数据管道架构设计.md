## 1. 总体架构（四层）

```
┌─────────────────────────────────────────────────────────┐
│  采集层 Collector   CNIPA / 企查查API / 招聘 / 新闻爬虫     │
├─────────────────────────────────────────────────────────┤
│  预处理层 Processor  文本→SciBERT向量；结构化→填充/剔除/Z   │
├─────────────────────────────────────────────────────────┤
│  特征层 Feature     按《特征工程字典》产出企业级特征表      │
├─────────────────────────────────────────────────────────┤
│  服务层 Service     FastAPI：批量评估 + 单企业深度诊断      │
└─────────────────────────────────────────────────────────┘
```

设计原则：**配置化**（源 / 口径走 config）、**可复现**（同输入同输出，随机种子固化）、**模块化**（每层独立可单测）。

## 3. 预处理流水线

### 3.1 非结构化文本 → SciBERT 向量
- 入口：`src/data/load_scibert.py`（`load_scibert` + `encode_text`）。
- 流程：专利摘要 / 新闻正文 → tokenizer → SciBERT（768 维）→ 句/段向量 → 企业级聚合（mean-pooling 或 attention）。
- 输出：`company_id → embedding[768]` 存入特征层，供图谱语义边（T21）与融合特征（5.1）消费。

### 3.2 结构化数据 → 标准化
统一三步（优先 P0 字段）：
1. **缺失填充**：P0 缺失 >30% 剔除企业；其余用组内中位数填充。
2. **异常剔除**：IQR（1.5×）或 3σ 法剔除离群，记录剔除日志。
3. **Z-score 标准化**：`(x - μ) / σ`，按指标分组标准化，保留原始值列备用。

> 专利被引稀疏（零值多）：先做 `log(1+x)` 变换再标准化。

### 3.3 统一接口
```python
@dataclass
class ProcessedSample:
    company_id: str
    quarter: str
    features: Dict[str, float]      # 对应字典 §6 字段
    text_embedding: np.ndarray      # [768]
    milestone_flags: Dict[str, bool]
```

## 4. 后端 API 设计（FastAPI）

两种模式（对应交付物）：
- **批量评估**：上传 Excel / CSV → 批量信用分。
- **单企业深度诊断**：图谱 + SHAP 解释联动展示。

| Method | Path | 说明 |
|---|---|---|
| POST | `/api/batch-evaluate` | `multipart/form-data` 上传文件 → 返回信用分列表 + 因子概览 |
| POST | `/api/diagnose/{company_id}` | 返回该企业图谱邻接、关键因子 SHAP、决策图谱 JSON |
| GET  | `/api/health` | 环境 / 模型加载状态自检 |
| GET  | `/api/schema` | 返回特征表字段定义（对接前端 T61） |

- **模型加载**：STGNN（T31）与解释器（T40/T41）懒加载，首请求预热。
- **鉴权**：内部先用，预留 `X-API-Key` 中间件待部署时启用。
- **技术栈**：FastAPI + uvicorn + pydantic（已在 venv 验证）；文件解析用 pandas / openpyxl。

## 5. 数据表 Schema（初稿）

主键统一 `company_id`（企查查 `cid` 或统一社会信用代码）。

| 表 | 字段要点 | 用途 |
|---|---|---|
| `companies` | company_id(PK), name, credit_code, reg_date, industry | 企业主表 |
| `company_quarter` | company_id(FK), quarter, rev_cagr, emp_cagr, patent_cagr, milestone_flags | 时序（支撑 T22） |
| `patents` | patent_id(PK), company_id(FK), ipc_class, apply_date, grant_date, citation, triple_score | 技术要素源 |
| `financings` | round_id(PK), company_id(FK), date, amount, post_val, investor_id | 融资 / 投资机构 |
| `investors` | investor_id(PK), name, prestige_level | 投资机构知名度 |
| `feature_table` | company_id(PK), 15 个特征字段（对应字典 §6） | 模型输入主表 |
| `graph_snapshots` | snapshot_id(PK), quarter, edge_list, node_feat | 时空图谱切片（T23） |

> `feature_table` 字段与 `docs/特征工程字典.md §6` 严格一一对应，改口径须先改字典。
