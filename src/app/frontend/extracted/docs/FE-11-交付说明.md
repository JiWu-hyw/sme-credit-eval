## 二、四区块交付明细

### A01 数据接入链路（`/api/data/pipeline`）

- **画法**：手写 SVG 三列布局（源 / 处理 / 数据集），不用 ECharts —— 链路图节点少、要可键盘聚焦、要能逐节点断言，SVG 比 canvas 划算。
- **内容**：12 个节点、10 条边、6 步流水线。首步写死「按 userid 分组切分」，并在详情里说明为什么不能用行级随机切分（同一企业跨月样本会同时落进训练与验证，指标虚高）。
- **状态**：每个节点带 `status`（ready / partial / pending / blocked / synthetic_only），配色与图例一致。
- **可断言性**：节点 `<g>` 带 `data-node-id` / `data-status`，浏览器冒烟直接数节点数与契约对账。

### A02 数据质量诊断（`/api/data/quality`）

- **顶部 KPI**：字段数 14、平均缺失率 18.1%、缺失 >30% 字段 3 个、语义已知字段占比 0.0%（红线二的适用面直接摆在台面上）。
- **缺失率热力图**：14 字段 × 4 列（2021 / 2022 / 2023 / 整体）= 56 格，四档色（<10% / 10–30% / 30–50% / ≥50%）。
  - **不只靠颜色**：每格 `title` 写成「x021 · 2021 缺失率 2.1%」，色盲用户与截图归档都能读。
  - 支持「原始顺序 / 按缺失率降序」切换。
- **缩尾前后箱线图**：ECharts `custom` 系列画 q05–q25–中位–q75–q95，灰=缩尾前 / 红=1%/99% 缩尾后，**两组按 2×N 槽位并排**；图下注明「边界只在训练集拟合，验证/测试集直接套用，不回滚」。
  - 修于 2026-10-22 复核：原实现用 `idx±0.18` 在 **category 轴**上做偏移，坐标会被吸附回整数刻度 → 两组箱体完全重叠，图上只剩红色。改为 2×N 槽位（`x021·前 / x021·后`）+ 槽内 ±0.16 偏移，并顺手修掉 `fill: 'var(--risk-high-risk)'`——canvas 不解析 CSS 变量，之前箱体填充是透明的。
- **字段明细表**：字段 / 缺失率 / 缩尾 / 非空样本 / 偏度，缺失率超阈值的行标色。

### A03 面板观测纵深（`/api/data/panel-depth`）

- **直方图**：每企业观测月数分 5 箱（1 月 412 / 2–3 月 358 / 4–6 月 171 / 7–12 月 58 / 13–24 月 18），柱状 + `markLine` 中位线。
- **结论前置**：中位 2 月、均值 2.06、P90 为 6 月，页面直接给判断句「**24.3% 企业达标 ≥6 月，长序列建模不可行**」，不把推断甩给读者。
- **噪声地板**：同屏挂 0.477 的地板条，解释「真实面板行级 AUC≈0.59 离抛硬币并不远」。
- **口径核对**：分箱企业数合计 = 1017 = `coverage.enterprises_with_panel`，接口冒烟脚本专门断言这一条，防止分箱与汇总各算各的。

### A04 特征体系三级树（`/api/features/tree`）

- **结构**：3 个一级维度（技术要素 / 成长轨迹 / 融合特征）→ 8 个二级子类 → **11 个叶字段**（进模型 6 个）。
- **折叠**：一级、二级均可折叠，按钮带 `aria-expanded`；提供「全部展开 / 全部收起」。
- **字段详情浮层**：点叶子开右侧抽屉，内容为 数据类型 / 缺失率 / 缺失处理 / 缩尾 / 标准化 / 是否入图 / 是否进模型 / SHAP 排名 / 语义状态 / 备注，底部给 `label_ref`（如 `feature_dict.x037`）。
  - 可访问性：`role="dialog"` + `aria-modal="true"` + `aria-labelledby`，打开自动聚焦关闭按钮，Esc 关闭。
- **阻塞说明**：树顶明确标出 `blocked_by`：P0-1 `userid→企业` 映射键、P0-2 `x21–x200` 字段字典。

### 数据导入入口（FE-20 挂点）

## 三、接口与契约

四个端点全部走 `src/api/index.ts` 收口（页面从不 import axios / mock），mock 通道按 `VITE_USE_MOCK` 三态切换：`mock` / `real` / `auto`（默认，真实接口失败或命中 `CONTRACT_PENDING` / `LABEL_PENDING` 自动降级）。

| 端点 | 契约文件 | 大小 | 关键计数 |
| --- | --- | --- | --- |
| `GET /api/data/pipeline` | `outputs/contracts/data_pipeline.json` | 6,364 B | 12 节点 / 10 边 / 6 步 |
| `GET /api/data/quality` | `outputs/contracts/data_quality.json` | 13,575 B | 14 字段 / 42 热力格 / 12 条箱线（before+after） |
| `GET /api/data/panel-depth` | `outputs/contracts/panel_depth.json` | 1,675 B | 5 档分箱 / 1017 企业 / 中位 2 月 |
| `GET /api/features/tree` | `outputs/contracts/feature_tree.json` | 16,198 B | 3 一级 / 8 二级 / 11 叶 |

契约由 `scripts/build_data_contracts.py` 生成，`--demo` 模式用固定种子（20261022）复现结构同构的占位数值，`meta` 里强制带：

```json
{ "source": "demo_placeholder",
  "disclaimer": "结构同构占位数据…不得作为任何实证结论引用",
  "dataset": "real_panel", "noise_floor": 0.477, "semantic_known": false }
```

**前端必须原样透出 `disclaimer`**，页面顶部有独立的占位告示条。真实面板落盘到 `data/processed/` 后，把 `load_real_panel()` 接上、去掉 `--demo` 即可产出实测契约，**前端零改动**（契约结构不变）。

类型镜像在 `src/types/contracts.ts`，字段名与契约逐字对齐（snake_case，不做 camelCase 转换、不简化结构）。

## 四、红线落地：不是文案，是机制

| 红线 | 契约 | 落地方式 | 被谁守住 |
| --- | --- | --- | --- |
| ① 同一图表不得混排数据来源 | §6.3 | `ChartPanel` 的 `dataset` 是**必填 prop** → 缺角标是编译错误；`assertSingleDataset()` 组装 series 前运行期抛错 | `redline-smoke` 6 项 + `layout-smoke` |
| ② 语义未知字段只显代号 | §6.5 | `UnknownFieldTag` 统一渲染 `xNNN`；`assertFieldDisplayable('营业收入', false)` 直接抛错；页面上全页只挂**一条** `RedLineBanner`，七页不各说各话 | `redline-smoke` 7 项 + P2 浏览器 3 项 |
| ③ 真实面板图同屏噪声地板 | §6.4 | `ChartPanel` 见 `dataset === 'real_panel'` 且传了 `noiseFloor` 自动挂 `NoiseFloorNote`，不靠调用方记得；`hasNoiseFloor()` 判定缺地板即不合格 | `redline-smoke` 5 项 + P2 浏览器 2 项 |
| ④ 不同来源不同图 | §6.3 | `mixed` 是合法**标注**但不能与具体来源并存；角标对 synthetic / mixed 强制 warning 基调（不与实证结论同观感） | `redline-smoke` 4 项 |

浏览器层实测：全页 `redline-banner` 恰好 1 条、未知字段代号 39 处、图表容器角标 2 处、噪声地板 0.477 出现在同屏。

## 五、取数纪律与异常态

- **骨架屏**：`useAsyncSection` 统一 300ms 阈值 —— 秒回不闪骨架，慢才亮。
- **竞态守卫**：每个区块带 `requestId`，切页/重试时旧响应丢掉，不串数据。
- **空态 / 错误态**：一律 `StatePanel`，**必填 `reason` + `nextStep`**，错误态另带重试按钮与技术摘要（`role="alert"`，读屏立即播报）。
- **四区独立取数**：一个接口挂了其余照常渲染；≥2 个失败时给一次批量重试。
- **不白屏**：断网、懒加载 chunk 失效由 `App.vue` 的 `onErrorCaptured` + `router.onError` 兜底，整页替换成可读错误态但保留导航。`auto` 模式下后端不可用会自动降级 mock 出图。

## 十、本版新增：P4 / P5 上线 + 线上白屏修复

### 10.1 线上白屏（先修的这个）

现象：分享链接打开后页面只闪一下，随即整页变成错误态；本地 dev 却完全正常。

根因链（逐层验证过，不是猜的）：

1. 前端在 `auto` 模式下请求 `/api/data/pipeline`；
2. 静态托管对未命中的路径回落 `index.html`，于是**返回 200 + 一段 HTML**；
3. axios 认为请求成功，`res.data` 是字符串，没有 `code` 字段，既不命中 `CONTRACT_PENDING` 也不报错；
4. HTML 被当成信封交给页面，页面读 `pipeline.nodes` 得到 `undefined`，在 `.filter()` 上抛 `TypeError`；
5. `App.vue` 的 `onErrorCaptured` 兜底，整页替换成错误态 → 用户看到的就是「闪一下」。

修了两处，缺一不可：

| 层 | 改动 | 作用 |
| --- | --- | --- |
| 前端 `src/api/index.ts` | 新增 `isEnvelope()` 形状校验：`code` 必须是数字/字符串、`data` 必须存在且不是字符串 | 非约定响应（HTML / 登录页 / 网关错误页）在 auto 模式下降级 mock，不再污染页面 |
| 静态服务 `serve/server.mjs` | `/api/*` 一律 404 + JSON，**绝不**回落 `index.html` | 不再制造「200 + HTML」这种欺骗性响应 |

另外给 P2 的四个区块加了**逐块 payload 守卫**（`hasArrays`）：某一块的形状不对只让那一块进空态，不会把整页顶掉。

回归：`npm run test:api` 里新增 3 项（`isEnvelope` 存在 / 拒绝字符串 data / 降级 mock），`npm run test:dist` 新增 12 项在**生产构建 + 静态服务**上直接验「刷新后正文仍在」。

### 10.5 这一轮踩的两个坑

1. **SSR 断言「正文区块」是错的**：`useAsyncSection` 的 300ms 骨架阈值在 Node 里永远不会到点（没有定时器跑），首版路由冒烟因此对 P4/P5 报「区块标记缺失」。但真实浏览器里 Vue 的 `<Suspense>` 会等 async setup 的 microtask，首屏其实是正文。结论：正文断言必须放真浏览器，SSR 只断言页头。
2. **Top-20 表格被 `max-height: 460px` 截成 13 行**：截图归档时会被误读成「数据只有 13 条」。实测 20 行 × 33px + 表头 = 692px，已改成 700px。

### 11.3 页面结构

1. **一句话结论**：模型学到了东西，但无法解释，也不足以支撑放贷决策。瓶颈不在算法在数据。
2. **四个 KPI**：行级 AUC / 企业级 AUC / 解释占比 / 观测中位月数，每个都标了来源页，可点进去看原始图。
3. **方法链路 6 步**：固定 3×2 排布（不按 auto-fit，否则 5+1 断行会让「多源融合」孤立成第二段流程）。每步带代码落点（`src/...py`）与状态标签，如实标 pending / synthetic_only。
4. **数据缺口 3 条**：P0-1 映射键 / P0-2 字段字典 / P0-3 语料，每条写清「影响 → 后果 → 依据 → 波及哪些页面」。
5. **交付进度 7 格**：已交付的格子是链接，未交付的灰显并注明依赖。

一个刻意的取舍：**概览页不重复画 P2/P4/P5 的图**。AUC 柱状图在 P4、SHAP 在 P5、箱线图在 P2，搬过来只会变成缩略图集，且两页数据一旦不同步就自相矛盾。这里只放数字和入口。

### 11.4 这页最大的风险：数字对不上

概览抄了另外三页的数字。任何一个源契约改了而概览没跟上，就会出现「两页看着矛盾」——
这种错误在截图评审里几乎看不出来。

所以 `scripts/p1-smoke.mjs` 的核心不是「能不能打开」，而是 **KPI 交叉核对**：
取第 i 张 KPI 卡片上的值，与它声明的 source 契约逐字比对（AUC、差值、占比、中位月数全部覆盖）。

**这里踩了一个必须记下来的坑**：第一版断言用 `整页文本.includes(...)`，
我把概览里的 AUC 故意改成 0.612，测试**照样全绿**——因为 0.596 还出现在别的句子里。
那等于没写。改成按卡片 DOM 取值后再改错，立刻 FAIL。教训：断言必须定位到「那个具体的元素」，
不能在一整页文本里大海捞针；写完要用「故意改错」验证它真的会红。
