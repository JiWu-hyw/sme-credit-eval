## 二、两区块交付明细

### A16 生存力预测（`forecast/survival`，A16，mock 契约）

**① Kaplan-Meier 生存曲线（可按风险组分层）**

- 三条曲线按 Cox 线性预测子三分位分层（低 / 中 / 高），每层 339 家；
- 阶梯图用 `step: 'end'` + `smooth: false` —— 生存函数只在事件时点下跳，插值成平滑曲线是伪造信息；
- **置信带**：每层一条 `custom` series 画 `polygon`，顶点由 `api.coord([t, S])` 现取像素坐标（不按固定宽高硬算，12 列栅格换视口不会错位）；
- 分层 chip：`全部 / 低风险 / 中风险 / 高风险`，切换只改**看哪几条**，不重算任何数字（曲线、CI、风险集都来自契约）；
- 纵轴自适应：按当前可见层的最低置信下界留 5% 余量后向下取整到 10%，**下限不低于 50%**。这一条是踩出来的 —— 1017 例只有 109 例事件，三条曲线全挤在 77%–100%，纵轴 0–100% 时带子只有几个像素高，「曲线含置信区间」在视觉上等于没交付；但也不能贴到数据底部，否则会夸大层间差异。

产物（`outputs/contracts/survival.json`，9.6 KB）：

| 分层 | n | 事件 | S(12) | 95%CI | S(24) | 95%CI |
| --- | --- | --- | --- | --- | --- | --- |
| 低风险层 | 339 | 11 | 0.9816 | 0.9670 – 0.9962 | 0.9658 | 0.9460 – 0.9857 |
| 中风险层 | 339 | 26 | 0.9472 | 0.9228 – 0.9717 | 0.9174 | 0.8869 – 0.9478 |
| 高风险层 | 339 | 72 | 0.8961 | 0.8629 – 0.9292 | 0.7709 | 0.7242 – 0.8175 |

队列整体：n=1017、24 个月事件 109 例（10.72%）、行政删失 24 个月 + 每月 0.6% 随机失访。

**② 分层检验**

log-rank（Mantel-Haenszel，超几何方差）：χ² = 63.83，df = 2，p = 1.38e-14。
页面渲染成 `p < 0.001` —— `formatP()` 统一处理，不让舍入后的 `p = 0.000` 出现在任何地方。

**③ Cox 系数表**

| `x125` | −0.5302 | 0.589 | 0.482 – 0.719 | −5.18 | < 0.001 |
| `x193` | +0.4772 | 1.612 | 1.327 – 1.957 | 4.82 | < 0.001 |
| `x60` | +0.4849 | 1.624 | 1.363 – 1.935 | 5.43 | < 0.001 |

### A17 融资力预测（`forecast/financing`，A17，mock 契约）

**① 概率校准曲线 + 指标卡**

| 指标 | 值 | 读法 |
| --- | --- | --- |
| Brier | 0.1499 | 越低越好 |
| Brier 基准（恒用总体发生率） | 0.1772 | 低于它才说明概率有增量信息 |
| Brier 技能分 | 1 − 0.1499/0.1772 = 0.154 | 有增量，但不大 |
| ECE | 0.0258 | 分箱加权偏差 |
| 可靠性斜率 | 1.0602 | 理想值 1（> 1 说明预测过于保守） |
| AUC | 0.7567 | 判别力 |

- 分箱：按**预测概率等频十分位**（不是等宽）—— 等宽会在低概率区挤出大量空箱；
- 区间：**Wilson 得分区间**。低概率箱里 Wald 会给出负下界，本页不用；
- 两轴同量程：45° 参考线只有在两轴同标度时才成立，写成 0–100% vs 0–60% 就成了一条假对角线。

**② 估值区间条（P10 / P50 / P90）**

- 8 条，单位万元，目标是「未来 6–12 个月下一轮融资的投前估值」；
- 横向区间条 + 端帽 + P50 竖线 + 数值标签；按 P50 降序；阶段色为有序渐变（种子 → 扩张）；
- 汇总：P50 中位数 3750 万元，**P90/P10 中位宽窄比 6.3×**；
- 页面明说：条越长越不确定，`P90/P10 = 6.3×` 意味着「同一家企业的估值上下能差这么多」，
  只报 P50 等于把这条长度藏起来 —— 这种区间没有决策价值，是**方法演示**不是对外结论。

## 三、接口与契约

### 3.1 两份新契约与既有实测数据的锚定关系

合成队列不是凭空编的，有三处硬锚点（脚本内有断言，不满足直接 `SystemExit`）：

| 锚点 | 来源 | 用途 |
| --- | --- | --- |
| n = 1017 | `panel_depth.json › enterprises_with_panel` | 队列规模与真实面板一致 |
| 24 月事件率 = 10.7% | `benchmark.json › 75/698` | λ 由二分法校准命中该目标（λ=0.001063，Weibull k=1.3） |
| 6 个协变量 | `shap_global.json` XGB Top-6 | 字段与 `direction` 符号一一对应（`if (beta > 0) != (direction > 0): raise SystemExit`） |

也就是说：**队列是假的，但它长在真的骨架上面**。这样等 P0-3 / P0-5 到位时，把数据源一换即可，接口形状不用动。

### 3.2 契约形状

```jsonc
// survival.json
{
  "meta": { "dataset": "real_panel", "source": "demo_placeholder", "contract_status": "mock",
            "label_status": "LABEL_PENDING", "n_samples": 1017, "seed": 20261033,
            "noise_floor": null, "chart": "A16", "disclaimer": "…" },
  "data": { "chart", "status", "status_note", "event_definition", "cohort", "axis",
            "strata", "curves", "logrank", "cox", "unlock", "derived", "derivation" }
}
// financing.json
{ "meta": {…同上，"chart": "A17"},
  "data": { "chart", "status", "status_note", "calibration", "valuation", "unlock", "derived", "derivation" } }
```

`curves[].points` 每行 6 列：`[月, S(t), CI下界, CI上界, at-risk, 累计事件]`，二维数组压成一行以便体积可控且可 diff。

### 3.3 确定性合成 + 反演自校验

- **确定性**：自写 LCG（`LCG(seed=20261033)`，无 numpy 依赖），同一 seed 两次运行逐字节一致；
- **反演自校验**：脚本用同一份队列**重新拟合** Cox，把拟合 β 与生成 β 对比，要求偏差 < 3.5SE —— 这是「估计器写对了」的证据；
- **不要求符号逐字段相同**：`x59` 这类弱效应在 109 个事件下 SE ≈ 0.10，本来就可能反号。要求它逐字段显著等于真值，等于要求数据比现实更干净，那是自欺。这条判断写在脚本注释里，避免后来者"修好"它；
- **seed 为什么是 20261033**：20261028 下低风险层前 12 个月零事件，Greenwood 方差退化为 0，CI 变成 `[1.000, 1.000]`（等于没有区间）。扫描 13 个 seed 后选了这个 —— 低风险层第 1 年出现 2 例事件，S12 = 0.9816 [0.9670, 0.9962]。

## 五、取数纪律与降级

### 5.1 两层守卫

```
getMock / HTTP 200  →  ① 信封形状校验（isEnvelope，防「HTML 当信封」）
                    →  ② 结构守卫（必须 curves/strata/cohort 或 calibration.bins/valuation）
                    →  ③ 才交给区块渲染
```

第 ② 层是本页新加的：信封合法但业务字段缺失（契约被截断、字段被改名），只有它拦得住。

### 5.2 降级边界（这里返工了三轮，坑都记在 `scripts/p6-shots.mjs` 顶部）

| 尝试 | 结果 | 原因 |
| --- | --- | --- |
| `page.route('**/forecast/survival')` 拦截 | ❌ 一次没命中 | mock 模式下 `call()` 直接 `return getMock(key)`，压根不发 HTTP。截到的"降级页"其实是正常页（md5 与 `p6-full.png` 相同） |
| 浏览器里劫持 `http.get` | ❌ 无效 | Vite dev 按需编译，`page.evaluate` 里 dynamic import 拿到的是另一个模块实例 |
| stub 后端返回 500 | ❌ 页面照常 | **auto 模式的既定行为就是「后端挂了回落 mock」**，500 被 `call()` 吃掉。500 根本不是本页降级分支的触发条件 |
| **real 模式 + 200 畸形信封** | ✅ 有效 | 不兜底，畸形信封原样交给页面 → 结构守卫 → pending 面板 |

> 这条经验值得记下来：**「我测了降级」和「降级真的发生了」是两件事。**
> 前三次的截图都是假的，只是当时没人比对 md5。

最终两组场景（`npm run test:p6` 内置，也在 `npm run shots:p6` 里出图）：

| 场景 | 结果 |
| --- | --- |
| 只打空 A16 | A16 降级面板 1 个、KM 图撤掉；**A17 校准图照常**、A17 无降级面板 → 区块级隔离成立 |
| A16 + A17 都打空 | 2 个降级面板、页头仍在、读图问答 5 条仍在、正文 2239 字、0 报错 → 不白屏 |

**刻意不含的两个判据**（写进脚本注释，防止后来者"补全"）：

- **结论区不要求仍在**：三句话每条都引用契约数字（S(24)、Brier、宽窄比），两契约都缺时它本来就该不显示，硬留个空结论区是错的；
- **mock 声明条不要求仍在**：文案取自 `meta.disclaimer` 与 `unlock`，契约缺了就没话可说。此时硬造一条"本区块为占位数据"的横幅反而是在撒谎（我们并不知道数据是什么来源），降级面板的「原因 + 下一步」已经讲清了。

### 5.3 角标缺省值

`source` 缺省不能落到 `'unknown'` 再进角标 —— 角标会把 `unknown` 原样印出来，读者看到 `真实信贷面板 · unknown`，比"占位数据"更难看也更没信息。改为：契约缺 `source` 时按 `contract_status` 推断（`mock → demo_placeholder`，否则 `contract_spec`）。这是本轮修的一个小 bug。

## 九、已知限制与后续

| 限制 | 影响 | 解锁条件 |
| --- | --- | --- |
| **队列是合成的** | 所有数值不可作为实证结论引用 | **P0-3**（事件口径：违约还是经营异常？观测窗内还是窗外？）+ **P0-5**（融资事件表：时间/金额/投前投后估值） |
| 企业级随访窗口不足 | 真实面板每企业中位仅 ≈2 个月观测，24 个月随访在真实数据上尚不成立 | 面板纵深（P0-4）扩展 |
| 估值区间是区间口径演示 | `P90/P10` 中位 6.3×，宽到没有决策价值 | P0-5 真实成交价 |
| Cox 协变量业务含义未知 | 6 个字段全是代号，只能说方向与量级 | **P0-2**（字段字典），届时改走 `label_ref` |
| 分层依据是 Cox 线性预测子 | 三分位切点由队列定，换数据会变 | 数据到位后由后端输出切点，前端已按契约读 |

解锁后的改动量：**脚本只改读取源，同一套 KM / Cox / 校准实现不动，前端零改动** —— 这正是本页现在敢展示的原因：接口形状已经按真实数据设计好了。
